# What a model leaves out

I must decide what to leave out before I can calculate a result. I choose a boundary, fix some degrees of freedom, and approximate interactions. I also choose which observable will test the model.

I accept that models are incomplete. A model must select the features that matter for a question. I worry when accurate predictions make me forget the assumptions that made them possible.

## Abstraction is a scientific achievement

I treat a finite cluster, a pseudopotential, and a convergence threshold as deliberate choices in computational materials physics. Each choice sets a limit on what I can ask the model to explain.

For a simple confinement model, I can write:

$$E_g(r)=E_{g,\mathrm{bulk}}+\frac{A}{r^2}-\frac{B}{r}.$$

I use this equation to describe the competition between confinement and Coulombic effects. It makes that comparison clear by leaving out other details.

## Prediction is not yet explanation

I can reproduce a band edge with a model and still identify the wrong mechanism. Surface states, passivation, finite-size strain, and numerical choices can give similar results for different reasons. I therefore need convergence tests, structural checks, and comparisons with experiment.

I treat agreement between a model and a measurement as evidence of success. To explain that success, I must also examine which alternative explanations the evidence excludes.

## The boundary is part of the result

I state the limits of a claim as carefully as the claim itself. A conceptual widget is not a DFT calculation. A converged calculation does not, by itself, explain an experiment. A useful approximation does not give a complete picture of a system.

I use these distinctions to show what the evidence supports and where uncertainty remains.
